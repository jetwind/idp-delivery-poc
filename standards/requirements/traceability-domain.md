# 一物一码领域知识

## 1. 核心概念
- 一物一码：给每个最小销售单元分配全局唯一标识码，让「每件产品有一个身份证」。
- 码的类型：数字码（EAN-13/UPC）、二维码（QR Code）、DataMatrix 码。

## 2. 追溯码标准（GS1）
- GS1 是全球通用的商品标识标准体系，核心是 GTIN（全球贸易项目代码）。
- 追溯码 = 企业前缀 + 商品项目代码 + 序列号（SN）+ 校验位。
- 序列号是「一物一码」的关键：同一商品项目下，每件产品 SN 唯一。

## 3. 典型应用场景
- 扫码溯源：消费者扫码查产品从生产到流通的全链路信息。
- 防窜货：码与区域/经销商绑定，识别跨区域销售。
- 防伪：防伪码 + 查询次数校验（首次查询激活、异常查询告警）。
- 营销：扫码领红包 / 会员。

## 4. 关键业务规则（需求阶段需澄清）
- 赋码时机：生产下线时生成？还是出库时激活？
- 码的生命周期：生成 → 激活 → 出库 → 销售 → 失效。
- 层级关联：箱码、垛码与单品码的父子关联关系。
- 批量赋码与导入：支持批量生成/导入码。

## 5. 常见验收要点
- 追溯查询：输入码 → 返回产品全链路（生产、仓储、物流、销售）信息。
- 防窜货：码与区域绑定，跨区销售时告警。
- 码的唯一性、不可伪造性校验。
