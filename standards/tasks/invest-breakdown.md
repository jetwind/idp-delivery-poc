# INVEST 任务拆分规范

## 1. INVEST 原则
- Independent 独立：任务尽量互不依赖，可单独交付。
- Negotiable 可协商：细节可协商，不必一次定死。
- Valuable 有价值：每个任务对用户/业务有明确价值。
- Estimable 可估算：能估算工作量。
- Small 足够小：单个任务宜在 1~3 天内完成。
- Testable 可测试：有明确验收标准可验证。

## 2. 任务归属
- 每个任务明确归属到具体服务，标注「新建服务」或「升级现有服务」。
- 技术栈：后端 Java 21 + Spring Boot，前端 Vue 3 + TypeScript。

## 3. 依赖与任务环编排
- 明确任务间依赖（哪些任务必须在哪些任务之后）。
- 任务环（执行批次）：同一环内任务互不依赖、可并行；环与环之间串行。
- 环的粒度 = 一次可并行派发给多个子代理的工作量。
